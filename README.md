A single horror sentence, under 200 characters, written for the
[One Line, One Chill](https://make.fun/bounty/u-azazex-one-line-one-chill-6d4d5488)
bounty on make.fun ($5 in USDC).

The program writes one sentence to `entry.txt`: a found obituary, dated
tomorrow, with the cause of death left blank — dread that outlasts the
line, in a single breath.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

This writes the entry to `/tmp/out/entry.txt`.
